# 商品データ仕様（タグ6軸・データ項目）

要件定義書 6章「商品データ設計」を実装に落としたもの。正本は `src/data/products.json`。
D1 の `products` / `product_tags` テーブルへは `npm run seed:build` で生成した `seed.sql` を投入する。

## データの流れ

```
（将来）CSV ──▶ src/data/products.json ──┬──▶ クライアント側の診断スコアリング（scoring.js）
                                        └──▶ seed.sql ──▶ D1 products / product_tags（商品詳細ページ・運用分析）
```

- 診断のスコアリングは D1 を使わず、ブラウザが `products.json` と `diagnosis.json` を読んで行う
- D1 に持つのは「商品マスタ」と「診断ログ」のみ

## データ項目（1商品）

| キー | 必須 | 内容 |
| --- | --- | --- |
| `id` | ◯ | 内部ID（`p001` 形式）。スラッグ変更の影響を受けない安定キー |
| `maker_slug` | ◯ | URL用メーカースラッグ（英小文字・数字・ハイフン）。**メーカー実名NGの場合はここだけ差し替える** |
| `model_slug` | ◯ | URL用機種スラッグ |
| `name` | ◯ | 商品名 |
| `maker_name` | ◯ | メーカー名（表示用） |
| `method` | ◯ | 方式 |
| `wavelength` |  | 波長 |
| `output_w` |  | 出力（W、数値） |
| `portability` | ◯ | 可搬性 |
| `tags` | ◯ | 下記6軸のタグ（配列） |
| `comment` | ◯ | 運営者による選定コメント（1文以上） |
| `suitable_for` |  | 向いている用途（配列） |
| `not_suitable_for` |  | 向いていない用途（配列） |
| `handled_by_operator` | ◯ | 自社取り扱い区分（true で「運営元で取り扱い」ラベル） |
| `image` |  | 画像パス |
| `source` |  | 情報源 |
| `is_published` |  | false で非公開（省略時は公開） |

商品ページURL：`/products/{maker_slug}-{model_slug}/`

## タグ6軸

| 軸 (`tags.*`) | 値 | 個数 |
| --- | --- | --- |
| `use` 用途 | 薄板接合 / 厚物 / 異材接合 / 補修 / 自動化 | 複数可 |
| `material` 素材 | 鉄 / ステンレス / アルミ / 銅 / チタン / マグネシウム | 複数可 |
| `thickness` 板厚 | 0.5mm未満 / 0.5〜3mm / 3〜6mm / 6mm以上 | 複数可 |
| `environment` 環境 | 屋内 / 屋外 / 真空 / クリーン / ライン組込 | 複数可 |
| `price` 価格帯 | 100万円未満 / 100〜200万円 / 200〜400万円 / 400〜600万円 / 600万円以上 | **1つだけ** |
| `skill` 習得難易度 | 未経験可 / 経験者向け / 熟練者向け | **1つだけ** |

価格は実売価格を掲載せず、価格帯タグのみ表示する（決定事項）。

## 検証ルール（`npm run validate`）

- 必須項目の未設定、スラッグの文字種・重複
- 各軸が配列であること、価格帯・習得難易度は1つだけ
- 選定コメントが必須
- **1商品あたり平均10タグ以上**（下限を下回るとエラー）

## 診断との対応（`src/data/diagnosis.json`）

| 設問 | 軸 | 判定 |
| --- | --- | --- |
| Q1 素材 | `material` | 選択肢のタグを1つでも持てば適合。「複数」は3種以上 |
| Q2 板厚 | `thickness` | 同上。「混在」は3区分以上 |
| Q3 使用者 | `skill` | 熟練工＝全て適合 / 新人も＝未経験可・経験者向け / これから＝未経験可 |
| Q4 環境 | `environment` | 屋内 / 屋外 / ライン組込 |
| Q5 予算 | `price` | 予算以下の価格帯を全て適合とする |

- 「わからない」「未定」はその軸を採点から外す（候補が広がる）
- 適合した軸の重み（素材3・板厚3・使用者2・環境2・予算2）の合計がスコア
- 回答した全軸に適合＝「完全一致」。ゼロなら `relax.order`（予算→環境→使用者→板厚→素材）の順に1つ外して再検索し、外した条件を画面に明示
- TOP5 の枠配分：1〜3枠 適合度順 / 4枠 専門用途（アルミ・銅・チタン・マグネシウム・真空・屋外・ライン組込のタグ持ち） / 5枠 価格重視（残候補の最安価格帯）
