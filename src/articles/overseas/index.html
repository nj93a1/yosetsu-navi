選び方ガイド

海外製（中国製など）を選ぶときのポイント

手持ちのレーザー溶接機は、日本のメーカーや販売店が扱う機種でも、海外で製造されているものが多くあります。製造国だけで良し悪しは決まりません。導入した後に困らないよう、買う前に確かめたい点をまとめました。

本サイトの機種ページの「製造国」は、メーカーや販売店の公式サイトに書かれている場合だけ表示しています。本社は日本でも製造は海外、という機種もあります。

確かめたい8つの点

  1. 国内で修理を受けられるか
  2. 交換部品が国内にあるか
  3. 保証の範囲と期間
  4. 日本語の取扱説明書と安全表示
  5. 電源とガス
  6. 公表値の読み方
  7. 補助金・税制を使う場合
  8. 販売店の体制

1国内で修理を受けられるか

故障したときに、どこで直すかを最初に確かめます。海外メーカーの機種でも、国内の代理店やメーカーの日本法人が修理を受け付けている場合があります。

  • 修理の窓口はどこか（メーカーの日本法人・国内代理店・購入した販売店）
  • 技術者が来てくれるのか、本体を送り返すのか
  • 修理にかかる日数の目安と、そのあいだ代わりの機械を借りられるか

2交換部品が国内にあるか

保護ガラス（保護レンズ）やノズルなど、使えば減る部品は定期的に買い足します。発振器やトーチケーブルが壊れたときの取り寄せ期間も確かめます。

  • 消耗品の国内在庫と、注文してから届くまでの日数
  • 発振器・チラー（冷却装置）が故障したときの対応

3保証の範囲と期間

保証の期間は、本体・発振器・トーチなど部品ごとに違うことがあります。保証を受ける窓口が海外のメーカーなのか、国内の販売店なのかも確かめます。

4日本語の取扱説明書と安全表示

手持ちのファイバーレーザー溶接機の多くは、目や皮膚への危険が大きい「クラス4」のレーザー製品です。日本では JIS C 6802 がレーザー製品の安全基準で、厚生労働省の通達「レーザー光線による障害の防止対策について」が、管理区域の設定や保護めがねの着用などを求めています。

  • 日本語の取扱説明書と、日本語の警告表示があるか
  • レーザーのクラス表示と、使う人に必要な保護具が示されているか
  • 操作と安全の講習を、導入時に受けられるか

5電源とガス

工場の電源で使えるかを確かめます。海外向けの仕様のまま、三相380Vの機種もあります。日本の工場で一般的な三相200Vや単相200Vでない場合は、変圧器が要ります。

  • 必要な電源（単相200V・三相200V・三相380V）と、消費電力・ブレーカーの容量
  • シールドガス（アルゴン・窒素）の種類と流量

6公表値の読み方

カタログの数値は、書き方がメーカーごとに違います。

  • 「溶け込み深さ」は、溶ける深さです。「溶接できる板厚」とは違います
  • 出力は「定格（連続）」と「最大ピーク」で値が大きく変わります
  • 自社で使う材料と板厚でテスト溶接をして、仕上がりを確かめるのが確実です

7補助金・税制を使う場合

補助金や税制には、製品や購入先についての条件があります。

  • 省力化投資補助金（カタログ注文型）は、製品カタログに登録された製品を、登録された販売事業者から買うことが条件です
  • 中小企業経営強化税制では、工業会等の証明書が必要です。メーカー（または国内の販売元）が証明書の手続きに対応しているか確かめます

補助金・助成金・税制の一覧もあわせてご覧ください。

8販売店の体制

同じ機種でも、販売店によって導入時の支援が違います。設置と試運転、操作講習、デモ機やテスト溶接の有無を比べます。

買う前のチェックリスト

  • 修理の窓口と、修理中の代わりの機械
  • 消耗品の国内在庫
  • 保証の期間と窓口
  • 日本語の取扱説明書と警告表示、安全講習
  • 工場の電源で使えるか（380V なら変圧器）
  • 自社の材料でのテスト溶接
  • 補助金・税制の条件（登録製品・証明書）
国内での修理・サポートを公式に記載している機種 テスト溶接で仕上がりを確かめる

テスト溶接は、本サイトの運営元（レーザー溶接機の販売事業者）が取り扱う機種で受け付けています。
