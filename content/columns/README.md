# コラムの書き方（content/columns）

1本の記事 = 1つのサジェストワード（Google の検索候補）。候補の一覧と進み具合は `keywords.json`。
`npm run build`（scripts/build-columns.js）で `/columns/{path}/` のページになる。

## 公開までの流れ

1. 記事案を `content/columns/{日付}-{path}.md` に書く。frontmatter に `draft: true` を入れる（ページは作られない）
2. 北坂社長（または担当）が内容を確認して承認する
3. `draft: true` の行を消し、`keywords.json` の status を `published` にする → テスト → 本番反映 → コミット

SEO ツール（kdm-seo-ops）の記事ジョブにつないだあとは、ジョブがこのフォルダに .md を 1 つ足す PR を週 1 本出す。
PR のマージが承認で、マージ後に本番へ反映する。

## frontmatter

```
---
title: 記事タイトル（サジェストワードを含める。20〜32文字）
date: 2026-10-16
path: ascii-kebab-case（URL。既存と重ねない）
description: 80〜120文字。誰に向けた何の話かと結論を前半に
keyword: サジェストワードそのまま（例：レーザー溶接機 価格 相場）
draft: true
---
```

## 書き方の決まり（このサイトは中立の比較サイト）

- 数字と事実は、メーカー・販売店の公開情報と、このサイトの機種データ（src/data/products.json）にあるものだけ。出典が無いことは書かない
- 価格は公開されている価格帯だけ。実売価格・値引き・運営元の価格は書かない
- 特定のメーカーを持ち上げたり、けなしたりしない。運営元（ノースヒルズ溶接工業）の機種に触れるときは、運営元の機種だと書く
- 文体は です・ます。一人称は使わない（必要なら「本サイト」）。1文は短く、段落は2〜3文
- 本文は1,200〜2,500字（字数を合わせるための水増しはしない）。構成は「導入 → ## 見出し2〜4本 → まとめ」
- まとめに営業文を置かない。機種を探す導線（診断・機種一覧・相談）はページのテンプレートが出す
- 記号のダッシュ（——）と感嘆符の連発は使わない
